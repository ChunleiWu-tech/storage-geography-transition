# 2025年末省域新型储能官方来源覆盖审计（2026-08-03）

## 结论

截至本次检索，国家能源局发布的《中国新型储能发展报告（2026）》给出全国精确功率/能量、华北和西北精确区域功率/能量，以及其余四区域的四舍五入占比，但未发布可直接用于模型的31省同截止日精确功率—能量表。因此不得把重建向量写作“官方逐省存量”或“观测实际存量”。

V2只新增两条满足“2025-12-31、已建成/并网、新型储能、排除规划/在建”的省级精确功率锚点：甘肃8405.8 MW、贵州2450 MW。连同国家能源局直接发布的内蒙古20260 MW、新疆18800 MW、山东11210 MW，精确省级功率锚点增至5个。其余省份继续在全国和区域闭合、官方排序与“超过5 GW”下限下透明重建。

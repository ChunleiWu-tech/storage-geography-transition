# 主模型上游：16 个源项锁定的正式场景

数据版本：`NEA_SWITCH_CHINA_SOURCE_UPDATE_20260803_V2`

本目录是论文主模型的正式上游入口。V17/V17T1 文件只保留用于版本追溯；正式运行统一使用 V17T2 启动器。

## 输入口径

- 研究模板来自冻结的 SWITCH-China v2.0.9 快照，经可审计的聚合、研究期扩展和储能约束扩展形成，不声称与原始快照逐字节相同。
- 2024 年风电校正目标为 `0.2532072175254301`。该值由国家能源局最终发电量 996.8 TWh、95.9% 利用率和月末装机积分推导，仅作为全国总风电对陆上风电小时形状的水平代理校正。
- 2025 年底既有新型储能固定为 135,930 MW/351,120 MWh。完整省级向量是 NEA 约束的模型重建，不是官方 31 省普查；核心区位比较采用共同 `2.583094239682189 h` 时长。
- `SL00_OBSERVED_ACTUAL` 是兼容性内部 ID，公开标签只能使用“重建时长敏感性”；不得描述为逐省真实 MWh 观测。
- 4 h 电池成本采用 NLR 2025 的完整系统低/中/高绝对成本轨迹。`SL12–SL15` 是 NLR 低/高成本的严格配对；其余场景使用中位轨迹。
- 旧人为成本比例、164 GW 容量轨迹、内生容量锚点和反向成本校准不属于当前模型。

## 正式运行

```powershell
$env:JULIA_EXE = "C:\你的Julia目录\bin\julia.exe"
$env:V17_SOLVER_THREADS = "10"
.\RUN_V17T2_CLEAN_REBUILD_AND_RUN_ALL_16_1x10.bat
```

兼容入口 `RUN_V17T2_UPSTREAM_FULL_16_1x10.bat` 会转到同一干净重建流程。该流程清除旧案例、旧结果和旧结果指纹，重建当前源项，准备并审计 16 个案例，逐个运行 Julia–Gurobi，并执行结果发布门。

只准备和验证输入、不求解：

```powershell
.\RUN_V17_PREPARE_ONLY.bat
```

输入准备完成后，源项门和案例门必须为 `PASS`；求解前结果门返回 `FAIL_RERUN_REQUIRED` 是预期行为。只有 16 个场景均获得求解器原生 `OPTIMAL` 证书、物理审计和当前源项结果指纹，主模型结果才可进入统一后处理。

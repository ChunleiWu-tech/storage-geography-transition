# Model-zone display coordinates

These coordinates are used only to place the 32 provincial/model-zone nodes in schematic network figures. They are approximate provincial-capital or zonal-centroid display points and are **not** administrative boundary data. The publication figures must label the panels as model-node schematics and must not use these points for area, distance, boundary or territorial calculations. Inner Mongolia is split into East and West model zones using display centroids.

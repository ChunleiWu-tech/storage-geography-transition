# Frozen source snapshots

The directory preserves the exact source files used to build the publication input contract. File hashes and evidence boundaries are recorded in `../OFFICIAL_SOURCE_ARCHIVE_INDEX.csv`.

- SWITCH-China v2.0.9 is the foundational open-model snapshot.
- The 2024 province-hour VRE file supplies temporal-spatial shape.
- The NEA 2024 monitoring document supplies final wind generation and utilization.
- The NEA 2026 storage report supplies the coherent end-2025 storage stock.

A source snapshot being archived does not imply that every study input is byte-identical to it. Study-specific aggregation, representative-period construction, policy assumptions and technology extensions remain a separate, versioned transformation layer.

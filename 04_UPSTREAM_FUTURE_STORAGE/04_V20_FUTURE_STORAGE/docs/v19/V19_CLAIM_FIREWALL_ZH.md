# V19 结论防火墙

1. **Layer A** 识别的是模型内受控 counterfactual 的 correction effect；不等价于历史数据统计因果。
2. **Layer B** 是长期容量扩张路径；不应拿来替代 Layer A 的 matched-pair 纠偏指标。
3. 月际联结代表日允许讨论跨月 SOC 机制，但不是完整 8760。
4. 单一气象基准不能支持多天气年可靠性结论。
5. LFP 8/10 h 只做时长成本结构敏感性，不作为 headline 技术排名依据。
6. CAES/H2 在省级地质资源账本缺失时只做 pressure test，不做真实站址/省级部署预测。
7. 非 LFP 2030 后默认冻结并非“认为技术不再进步”，而是 evidence-bounded 基准；长期 technology winner 必须配合学习路径敏感性解释。
8. build container 未执行 Julia/Gurobi 时，任何 prepared/static PASS 都不得写成 numerical/solver-certified PASS。

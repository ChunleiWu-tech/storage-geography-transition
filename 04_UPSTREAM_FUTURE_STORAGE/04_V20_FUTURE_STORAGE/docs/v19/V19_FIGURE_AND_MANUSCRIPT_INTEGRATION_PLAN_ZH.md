# V19 与现有论文主线的图文融合建议

V19 不需要重写前面已经跑完的主线图。推荐把它作为主线之后的一张“未来纠偏与规划”新主图。

## 主图建议：Future correction and adaptive storage planning

- **a**：BASE 与 ADAPTIVE 的 residual legacy penalty、correction value、repair fraction；
- **b**：2033 adaptive technology mix（MW/GWh/等效时长）；
- **c**：省区/模型区 × 技术新增容量；
- **d**：省区最优新增储能等效时长；
- **e**：Observed -> Optimized / BASE -> ADAPTIVE 的补偿性投资转移（储能、发电、输电）；
- **f**：TX-fixed 与 expanded pressure test 的稳健性。

这 6 个子图由 Layer A 提供，直接回答“已有空间锁定能否被未来灵活规划修复”。

## 长期扩展建议

Layer B 不与 Layer A 的 correction 指标混算。它单独提供：

- 2028–2058 各技术新增 MW/GWh 路径；
- 技术/时长份额演化；
- 省区迁移；
- 储能与输电协同演化；
- observed legacy 与 optimized legacy 两条长期路径的分化/收敛。

如果正文主图数量已满，Layer B 可作为一张独立主图或高信息量补充主图。正文机制表述应是：

`既有布局造成锁定 -> 2033 adaptive opportunity set 可修复多少 -> 长期系统通过何种技术/时长/空间路径完成修复`。

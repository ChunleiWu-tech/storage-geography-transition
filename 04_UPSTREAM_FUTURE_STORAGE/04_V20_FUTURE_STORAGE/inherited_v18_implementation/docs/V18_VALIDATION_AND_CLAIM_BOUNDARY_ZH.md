# V18 验证与结论边界

## 可作为主结论的内容（默认 evidence_bounded 模式）

- 中国 32 模型区层面的未来 LFP / VRFB / PSH 技术–时长组合；
- 各投资期 MW、MWh、等效时长结构与空间分布；
- 既有储能空间遗产对未来储能类型、时长和容量的影响；
- 储能与跨省输电扩建、发电扩张之间的系统级替代/互补；
- 在当前代表日+月间 SOC 链接框架下的中长期储能机制。

## 只能作为压力测试的内容

- CAES / H2 的全国或省区部署量（缺省级地质资源账本）；
- 2030 后非 LFP 成本学习（R1 默认冻结而非外推）；
- cycle-life / degradation 价值（R1 不设额外硬循环约束）。

## 当前禁止的表述

- “V18 已完成站点级最优选址”；
- “V18 已证明中国需要 X GW 的季节储能”；
- “V18 已进行多天气年可靠性优化”；
- “V18 代表日结果等价于 8760 连续运行”；
- “CAES/H2 省级容量为真实可开发地质潜力”。
